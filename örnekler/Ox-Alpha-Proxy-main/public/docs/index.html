Quick Start

npm install
npm start
# Open http://127.0.0.1:3000/chat — send a message!

curl http://127.0.0.1:3000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"ox-alpha","messages":[{"role":"user","content":"hi"}]}'
All endpoints are local-only by default. Set HOST=0.0.0.0 or use run.bat → option 2 for LAN.

Authentication Optional

If AUTH_TOKEN is set in .env, all API routes require:

MethodHeaderValue
MasterAuthorizationBearer <master>
ClientX-Client-Id + X-Client-TokenFrom /api/signup or /api/login

If AUTH_TOKEN is not set, all endpoints are open (local-only by default).

POST /api/signup
Body: { "username": "alice", "password": "secret" }
Response: { "clientId": "abc", "clientToken": "xyz" }

POST /api/login
Body: { "username": "alice", "password": "secret" }
Response: { "clientId": "abc", "clientToken": "xyz" }

Chat API (SSE)

This is the web UI backend — used by /chat.

POST /api/chat

Server-Sent Events stream. The chat UI sends and receives deltas in real-time.

{
  "message": "Hello, what can you do?",
  "chatId": "abc123",          // optional — auto-created if missing
  "images": [                  // optional — up to 4 images
    { "name": "screenshot.png", "dataUrl": "data:image/png;base64,..." }
  ]
}

SSE Events:

EventPayloadWhen
queue{"type":"queue"}Job queued (server busy)
thinking{"type":"thinking","text":"Reasoning..."}Model is reasoning
delta{"type":"delta","text":"chunk"}Streaming response chunk
done{"type":"done","text":"full response","chatId":"abc"}Response complete
error{"type":"error","error":"message"}Something went wrong

OpenAI-Compatible API

Works with Cursor, Cline, Windsurf, Zed, Continue, Copilot, opencode, hermes, aider, any OpenAI SDK.

Base URL: http://127.0.0.1:3000/v1

Aliases (for convenience):

RouteNotes
/v1/chat/completionsPrimary — works everywhere
/chat/completionsAlias (Cursor uses this)
/v1/completionsLegacy completions
/v1/messagesAnthropic format (Claude Code)
/v1/responsesResponses API (Codex, Cursor)

GET /v1/models

Response: {
  "data": [
    { "id": "ox-alpha", "name": "Ox Alpha — Stealth Reasoning Model, 1M context" },
    { "id": "ox-alpha-proxy", "name": "Ox Alpha Proxy" },
    { "id": "z-ai/glm-5.3-flash", "name": "GLM-5.3 Flash (via Ox Alpha)" },
    { "id": "openai/gpt-4o", "name": "GPT-4o (via Ox Alpha)" },
    { "id": "anthropic/claude-sonnet-4.6", "name": "Claude Sonnet (via Ox Alpha)" },
    { "id": "google/gemini-2.5-pro", "name": "Gemini 2.5 Pro (via Ox Alpha)" }
  ]
}

All model names map to Ox Alpha — the model field is ignored. Use any string.

POST /v1/chat/completions

{
  "model": "ox-alpha",        // any string — maps to Ox Alpha
  "messages": [
    { "role": "system", "content": "You are helpful." },  // optional — prepended
    { "role": "user", "content": "What is 2+2?" }
  ],
  "stream": true,              // default: false
  "tools": [],                 // optional — tool definitions
  "tool_choice": "auto",       // optional
  "response_format": { "type": "json_object" },  // optional
  "user": "session-id",        // optional — persistent chat per user
  "max_tokens": 4096           // optional
}

Streaming: SSE events of data: {"choices":[{"delta":{"content":"..."}}]} ending with data: [DONE]

Non-streaming: Returns {"choices":[{"message":{"content":"..."}}]}

System Messages

System messages from role:system are fully supported. They are prepended to the conversation. The AI has no enforced system prompt — it speaks naturally. Use system messages to set behavior per-request.

Anthropic API

For Claude Code: set ANTHROPIC_BASE_URL=http://127.0.0.1:3000/v1

POST /v1/messages

{
  "model": "claude-sonnet-4-20250514",
  "messages": [{ "role": "user", "content": "hello" }],
  "system": "You are helpful.",   // optional
  "max_tokens": 4096,
  "stream": false
}

Returns Anthropic format: {"type":"message","content":[{"type":"text","text":"..."}]}

Tool Calling

Full tool calling loop — same as opencode / hermes. Server instructs Ox Alpha to emit tool_calls, executes them in sandbox, feeds results back, loops until final answer.

Supported Tools

ToolDescription
bashRun shell commands (auto-detects powershell/cmd/bash/python)
pythonRun Python code
write_fileWrite files to sandbox
read_fileRead files from sandbox
list_filesList files in sandbox directory

Example

{
  "model": "ox-alpha",
  "messages": [{ "role": "user", "content": "List files in the current directory" }],
  "tools": [
    { "type": "function", "function": { "name": "bash", "description": "Run a shell command", "parameters": { "type": "object", "properties": { "command": { "type": "string" } }, "required": ["command"] } } }
  ],
  "tool_choice": "auto"
}

Flow: Model emits tool_calls → server executes in sandbox → result fed back → model continues → repeat until final text answer.

Sandbox & Files

Per-user isolated sandbox at ./sandbox/<user>/. Memory limit: SANDBOX_MEMORY_MB=512. Timeout: SANDBOX_TIMEOUT_MS=30000.

Files created via write_file are accessible at /sandbox/<user>/<path> and appear in chat with instant Copy / Download buttons — even single-line code gets auto-fenced.

Text-to-Speech

GET /api/tts?text=Hello&voice=en-US-AriaNeural

Returns MP3 audio stream. Default voice: en-US-AriaNeural (Edge TTS). Max chars: TTS_MAX_CHARS (default 2000).

Voices: en-US-AriaNeural, en-US-GuyNeural, en-GB-SoniaNeural, en-GB-RyanNeural, en-AU-NatashaNeural, en-IN-NeerjaNeural

Settings & Management

GET /api/settings

Response: { "systemPrompt": "..." }

POST /api/settings

Body: { "systemPrompt": "You are a helpful coding assistant" }
Response: { "ok": true }
System prompt is optional. The AI has no enforced identity — it speaks naturally. Use the settings prompt to add custom behavior.

POST /api/reset-session Master Only

Clear Playwright cookies for a fresh Ox Alpha session. Requires master token if AUTH is set.
